# Firula app 1.1.1

Build de loja. Versão 1.1.1 — iOS build 8, Android versionCode 106 (`appVersionSource: local`,
valores do `app.json`).

Por que não OTA: as 4 mudanças desde a 1.1.0 são só JavaScript, mas os builds da 1.1.0 foram
gerados localmente (Xcode/Gradle) e não enviam o canal ao servidor de atualizações, então não
recebem EAS Update de forma confiável. Esta versão passa a enviar `expo-channel-name: production`
(`updates.requestHeaders` no `app.json`): a partir da 1.1.1, correções só de JS podem ir por
`eas update --channel production`, sem revisão das lojas.

## Comandos (build local)

```bash
cd ~/project/firula/mobile
npx expo prebuild --clean          # obrigatório: versão e canal mudaram no app.json
cd ios && pod install && cd ..

# iOS: abrir ios/Firula.xcworkspace → conferir General: 1.1.1 (8) → Product › Archive
# Android:
cd android && ./gradlew bundleRelease
jarsigner -verify app/build/outputs/bundle/release/app-release.aab   # precisa: jar verified.
```

Ou pela nuvem: `eas build --platform all --profile production`.
