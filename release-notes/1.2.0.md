# Firula app 1.2.0

Build de loja. Versão 1.2.0 — iOS build 9, Android versionCode 107 (`appVersionSource: local`,
valores do `app.json`).

## O que entra

- **Campeonatos (tabela ao vivo)**: nova tela `app/campeonatos/[slug].tsx`, aberta também pelo link
  `firula.com.br/campeonatos/:slug` (Universal/App Link já cobre qualquer caminho do domínio).
  Categorias, grupos com classificação, chave por rodada ou completa, jogos com filtros e
  participantes. Atualiza sozinha a cada 8 s enquanto houver jogo em andamento.
- **Gancho na página do organizador**: abaixo do banner de votação aparece um card por campeonato
  publicado do organizador ("Ao vivo" ou "Ver tabela"), que abre a tela acima. Some quando não há
  campeonato publicado.
- **API sem chave fixa**: o app não envia mais o header `X-API-Key` (o backend deixou de exigir).

As duas mudanças são só JavaScript. Como a 1.1.1 já envia o canal `production`, elas também
poderiam ir por `eas update --channel production` sem passar pelas lojas. Esta versão de loja
existe para quem ainda está na 1.1.0 (que não recebe OTA) e para carimbar a feature nas notas.

## Comandos

```bash
# projetos nativos regenerados a partir do app.json (ios/ e android/ são gerados, não versionados)
npx expo prebuild --platform ios --clean
npx expo prebuild --platform android --clean

# iOS: Xcode → Product → Archive → Distribute (App Store Connect). Se o Xcode reclamar do Podfile.lock: cd ios && pod install
# Android: cd android && ./gradlew bundleRelease   (precisa do credentials.json com a upload key)
```
